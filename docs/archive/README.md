# Archive

These documents describe features that hikari no longer has. They stay for their reasoning, not as a guide to the code.

- `tester.md`: the tester of a hub, its plan, its gaps and their approvals, and its release lock.
- `environments.md`: the services that ran beside a tester's tests, and image releases.
- `bench.md`: bench procedures and the results that the user recorded.
- `e2e.md` and `e2e-answers.md`: the brainstorm and the answers that led to these specs.

`docs/specs/remove-e2e.md` removed them. The tag `archive/hubs-and-e2e` keeps the code as it was before the removal.
