Go here is plain. gofmt everything. Wrap errors with context, `fmt.Errorf("read the map: %w", err)`, and check every error. Small interfaces, defined where they are used. Table-driven tests with `t.Run` and names that say the case. No reflection, no init(), no clever generics where a loop reads better. A package comment says what the package is for. Exported names are documented in one sentence that starts with the name.
