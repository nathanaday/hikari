Python here is typed and small. Every public function has type hints and a one-line docstring that says what it returns and raises. Use dataclasses for records, pathlib for paths, enums for closed sets, and f-strings. Raise a named exception for each error a caller can handle, with a message that says what to do. No bare `except`, no mutable default arguments, no `import *`. Tests are pytest functions, one behavior each, named for the behavior: `test_cancel_refused_after_pick`. Format with black and sort imports with isort, or match what the folder already uses.
